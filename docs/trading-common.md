# 通用交易纪律（所有策略层共用）

> 适用前提：只买个股、不用 ETF、不加杠杆。个股没有指数的新陈代谢保护，会退市、会造假、会戴帽，所以所有纪律比 ETF 严格一档。
>
> 核心原则：**涨靠运气，不死靠纪律。** 每笔交易的盈亏由胜率 × 盈亏比决定，纪律的作用是砍掉大亏的那几笔，让整体期望值为正。
>
> 本文是**框架层**：所有策略共同遵守。止损幅度、时间止损、复盘窗口等**参数**由各策略层文档自定义覆盖，本文给出中线默认值。
>
> 本文所有百分比阈值均为初始默认值，可按个人风险偏好调整，但**改数值必须在盘后冷静时改，禁止持仓期间为迁就当前持仓而改**。

策略层清单与额度分配见总纲 [trading-discipline.md](trading-discipline.md)。

---

## 一、买入前通用纪律

- **一句话测试**：买入前必须能用一两句话说清"买它赚的是什么钱"。各策略层定义自己的合法赚钱清单（中线：分红 / 业绩 / 事件；短线：情绪发酵；长线：股息），说不出来 = 不买。
- **计划先行**：买入前写死三件事——目标价或兑现条件、止损价、持有周期。盘中不临时改。
- **排雷必过**：买入前必须走完本策略层的排雷清单（清单与强度分层，见各层文档；数据源与取数口径见文末附录），任一硬排雷项命中不买。
- **分批建仓**：任何买入至少分 2 笔，不一把梭（短线仓按其层规则执行，见短线文档）。

## 二、仓位与风险预算（总资金层面）

- **单票总风险 ≤ 总资金 2%**（含全部分批）：即该票从买入到止损，最大亏损不超过总资金 2%。
- **单笔委托风险 ≤ 总资金 1%**：每一笔委托单独计算，防单次冲动重手。
- 由此得出仓位公式（两条上限自动统一，不再各说各话）：

```
单票仓位上限 = min(25%, 2% ÷ 止损幅度)

例：止损 -8%  → min(25%, 25%) = 25%
    止损 -10% → min(25%, 20%) = 20%   （止损越宽，仓位自动越轻）
    单笔委托  ≤ min(单票上限, 1% ÷ 止损幅度)
```

- **单票仓位硬上限 25%**（即公式里的常数 25%，此处单列是给"归零"场景兜底）：归零保护针对的是**连续一字跌停、止损物理上无法成交**的尾部场景（衔接五、跌停预案）——止损纪律正常执行时亏损被 2% 风险预算封顶，只有止损失效时，唯一还在兜底的就是这条仓位上限。
- **策略层额度**：短线仓 ≤ 10%、长线红利仓 ≤ 30%、中线逻辑仓 = 余额。层间额度不得挪用（短线亏了不能"先用中线额度顶着"）。
- **永远不满仓单票，不加杠杆。**
- **残余风险声明**：以上预算按止损价可成交计算。跳空低开、流动性枯竭会使实际成交劣于止损价，单票亏损可能超过 2% 预算（止损 -8% 跳空 -12% 成交 → 约 3%）。这是体系明示接受的滑点成本，由 25% 单票上限兜底封顶；此类平仓按实际盈亏正常记录，**不算违纪、不触发额外处置**，无需另行归责。

## 三、总回撤线（系统性风险总闸，凌驾于各层纪律之上）

- 基准：**过去 250 个交易日（一年）内总资产最高收盘值**，滚动更新。不用历史最高——深回撤后基准永远高挂，触发线形同虚设；不用更短滚动窗口——基准漂移，同一段行情会算出不同的回撤。创新高自然抬高基准；触发降仓后基准**不重置**（重新冒险由恢复条件单独管辖，防止"刚触发就重置基准、立刻又能开仓"的漏洞）。
- **回撤 ≥ 15% → 强制降至半仓（各层等比降），并冻结一切新开仓**。这是防 2015 式整体下跌的总闸——个股纪律只防个股风险，防不了满仓齐跌。
- 恢复条件：总资产收复至回撤 ≤ 8% 以内，**且**经过一次周末复盘确认后，方可恢复正常仓位。双重条件防抄底冲动。

## 四、连败处置链（框架，参数可分层覆盖）

触发：**连续 N 笔计划内亏损平仓**（硬止损、逻辑止损、时间止损触发的亏损平仓均计入；按平仓时间顺序计）。期间任一笔**计划内、非违纪**的盈利平仓即重置计数；平手平仓不计数、亦不重置。

> **违纪交易（无论盈亏）不参与计数**，走第八节违纪通道单独处理：本条检测"策略进入亏损周期"，违纪规则检测"纪律失效"，两套警报独立，混算会互相污染处置动作。特别地，**违纪盈利不重置计数**——违纪赚到的钱比亏损更危险，它会让坏行为得到奖励、强化侥幸。

默认参数（各层可覆盖笔数与冻结时长，见层文档）：

1. **立即**：冻结该层一切新买入一周——含该层其他票的计划内分批加仓；已挂的止损 / 止盈条件单照常执行，存量持仓不受影响。
2. **一周后**：复盘完毕恢复交易，但该层仓位上限减半。
3. **解除**：恢复后出现任一笔计划内、非违纪的盈利平仓 → 恢复正常仓位上限。

分层细则：

- **各层独立计数、独立触发**：中线层连败只冻结中线层，短线层照常（不同策略的胜率结构不同，短线连败不必然说明交易者状态差）。
- **跨层升级**：同一时间**两层及以上同时处于触发状态** → 视为交易者本人状态问题，冻结全部买入，只留条件单自动执行。
- 不强制清仓存量：T+1 下恐慌性清仓的摩擦成本，本身就违反本文档精神；冻结买入 + 降仓已足够切断连败循环。

## 五、卖出执行细则（A 股微观结构，与策略无关）

- **止损单当天就挂好**。A 股没有原生止损单：用券商 App 的条件单功能（华泰、东财等均支持）；券商不支持的就录入 stock-monitor 持仓监控，盘中触发推送、当日人工执行。总之不允许"到价再手动决定"。
- **止损价一律按已成交各笔的加权成本价计**：分批建仓每成交一笔，当日即按新的加权成本重挂止损单。不按首笔价、不按末笔价——分批价差会产生"按哪笔算"的解释空间，统一封死。
- **止损触发当日必走，不等反弹**。止损价的具体数值分层定义，"必走"不分层。
- **T+1 例外（买入当日触发）**：当日买入的票当日触发止损，T+1 下物理上卖不出——顺延至**次日 9:15 集合竞价挂跌停价卖出**（机制同下条跌停预案：挂跌停价确保成交，实际按撮合价成交）。"当日必走"仅此一处例外，只顺延一晚：顺延期间不加仓、不改止损价，不允许"反正卖不出"变成事实上的再看一天。
- **跌停预案**（触发当日必走的物理补充）：
  - 当日：跌停价挂单排队，盘中开板即成交；
  - 收盘仍未成交 → **次日 9:15 集合竞价直接挂跌停价卖出**。集合竞价按撮合价成交，挂跌停价是为了排进价格优先队列确保成交，实际成交价通常优于跌停价；
  - **禁止**改挂高价"等反弹再卖"——此时纪律的唯一目标是从跌停里出来。
- **卖出后不复盘"如果没卖会怎样"**——这笔信息只用于统计，不用于懊悔。

## 六、持有中通用纪律

- **禁止摊成本**：个股亏了补仓是 ETF 的特权，个股没有。只有"逻辑没变、只是价格更便宜、且原计划就含分批"才允许按计划买下一笔，且须满足第二节的风险预算。
- **季度重检**：每季度财报后重跑一遍所在策略层的排雷清单，任一命中 → 逻辑止损（长线层为季度轻检 + 年度检视，见其文档）。
- **区分两种跌**：
  - 指数级 / 板块级的跌（大家都跌）→ 不是个股卖出理由，**但受第三节总回撤线管辖**（总闸触发了就执行总闸）；
  - 个股独立于板块的跌（别人涨它跌）→ 触发重检逻辑，查不清原因按逻辑止损处理。
- **盘中不看分时频繁操作**：盘中只处理已触发的纪律（已挂条件单自动执行、跌停预案执行），不产生新决策。新决策只能在收盘后冷静时做出，次日执行。

## 七、复盘框架（窗口参数分层）

> 为什么每笔必录：记忆会自我美化——赚的票记得清、亏的票忘得快，一年下来"感觉还行"但实际亏钱是常态，记录是唯一不被情绪篡改的证据。本节的降半仓、停用、砍层判断全部依赖逐笔数据算出的胜率与期望值；计划内亏损与违纪亏损的归因区分同样只有记录才做得出。没有记录，策略好坏只能凭感觉。

- **每笔必录**：买入日期 / 理由 / 策略层 / 计划（目标、止损、周期）/ 卖出日期 / 理由 / 盈亏。没有记录的交易等于没做。
- **滚动窗口统计**（窗口大小分层：中线 20 笔、短线 50 笔；长线笔数过少，改年度复盘）：
  - 每平仓一笔，重算本层最近窗口的：胜率、平均盈利 / 平均亏损、期望值 = 胜率 × 平均盈利 − (1−胜率) × 平均亏损；
  - 滚动窗口期望值 < 0 → 该策略层**降半仓**；
  - 连续两个**不重叠**窗口期望值均 < 0 → **停用该策略层**（存量按纪律了结，不再新增）。
- **错误归类**：每笔亏损标记归因——"计划内亏损"（止损正常触发，是策略成本）还是"违纪亏损"（没执行纪律）。**违纪亏损按笔数计**（违纪是行为问题，按金额计会被单笔大亏扭曲）：违纪笔数占比 > 20% 时，暂停开新仓一周，先修纪律。
- **砍层**：每季度按策略分层统计哪类赚钱哪类亏钱，砍掉持续亏钱的那类。
- **周末复盘（每周日，固定四步）**：
  1. 本周交易逐笔对照黑名单（第九节）标记违纪、写明违反第几条——第八节违纪通道的认定环节；
  2. 核对存量持仓合规：单票 / 层额度是否超限，各票止损条件单是否仍在挂；
  3. 更新总回撤状态（第三节）：当前回撤、是否触发、触发后是否满足恢复条件——恢复条件中的"周末复盘确认"即此步；
  4. 写出下周计划内操作清单（计划分批、到期的条件动作），盘中只执行清单、不新增。

## 八、情绪与行为纪律

> 本节条款针对同一件事：情绪接管决策的瞬间。刚止损的人最强烈的冲动是"马上赚回来"，所以止损当日全局冻结；分时波动实时刺激情绪，所以盘中只执行、不创造新决策；听消息的赚亏都无法归因、无法复制，所以只能作研究线索。冷静时（盘后、有记录）的决策质量天然高于情绪状态下的临时判断——本节的目的就是保证决策只发生在前一种状态下。

- **止损当日 = 买入冻结日**：当日任一层发生止损后，**所有层**的新买入一律停止——含其他票、其他层的计划内分批。止损意味着当天判断状态存疑，交易者只有一个，情绪不分层；已挂的卖出条件单不受影响。次日恢复。
- **连败强制休息**：见第四节连败处置链。
- **不听消息**：群消息、"朋友内幕"、大 V 荐股一律不作为买入理由；消息只能作为研究线索，必须自己走完本层的逻辑测试 + 排雷流程。
- **不在情绪高点做决定**：大涨日、大跌日、愤怒 / 兴奋状态下，只执行既有计划（含已挂条件单），不做新决策。
- **牛市纪律**：越涨越要按纪律走，"行情好随便买都赚"的时候是违纪亏损的温床。

### 违纪通道（黑名单命中后的处置）

- **认定时点**：每笔平仓在复盘时对照黑名单逐笔标记，不标记 = 复盘没做；**持续状态型违纪**（黑名单 1 / 8 / 11 / 12：满仓单票、加杠杆、回撤线触发不降仓、层间挪用）发现即认定，不等平仓。
- **持续状态型 → 限期整改**：发现次日起冻结全部新买入，**5 个交易日内**降回合规（只卖不买）；到期未整改 → 冻结延续直至合规，并按"纪律体系整体失效"记入年度复盘。
- **行为型（其余条款）→ 记录 + 短冻**：已发生的不可逆，记录违纪条款号，次日冻结该策略层新买入一天；属于"该走没走 / 该挂没挂"的（止损未执行、止损单未挂），发现当日立即补挂或市价执行。
- **统计升级**：违纪笔数占比 > 20% → 全局暂停开新仓一周（第七节）。
- 违纪交易无论盈亏不参与连败计数（第四节），盈亏按实际记录。

## 九、行为黑名单（一票否决，出现即违纪，全层适用）

1. 满仓单票
2. 计划外亏损补仓摊成本
3. 止损价到了不走（"再等等"）
4. 追涨停 / 追当日已大涨的票（短线层亦适用——短线只做低吸潜伏，见短线文档）
5. 听消息直接买入
6. 止损当日任何新开仓（含计划内分批——当日全部买入冻结）
7. 盘中临时改变既有计划
8. 加杠杆 / 借钱炒股
9. 卖出后懊悔式回买（情绪单）
10. 没做本层排雷清单就买入
11. 总回撤线触发后仍新开仓 / 不降仓
12. 层间额度挪用（用中线额度给短线仓腾空间等）

## 附录：排雷与选股数据源对照（执行口径）

> 原则：**财务数据一律取最新定期报告**（有修正公告以修正后为准）；查不到、口径存疑 = 该项不通过，排雷从严。适用于中线排雷七项、长线选股条件、短线知情项。

| 检查项 | 数据源（主 / 备） | 取数口径 |
|---|---|---|
| 质押率 | 东财 F10「股权质押」/ 同花顺 F10 | 质押股份 ÷ 总股本，取最新；红线 50% |
| 商誉占比 | F10 资产负债表 | 商誉 ÷ 归母净资产，最新季报；红线 30% |
| 立案调查 / 审计非标 | 巨潮资讯网公司公告（官方全量） | 搜「立案」「非标意见」；以公司公告为准，不以新闻转述为准 |
| 退市红线 | F10 财务摘要，对照交易所退市新规 | 连续亏损年数、营收利润组合指标 |
| 大股东减持计划 | 巨潮公告 / 东财「公告筛选」 | 近期披露的减持计划类公告 |
| 限售解禁 | 东财 F10「限售解禁」 | 未来 3 个月内解禁量 ÷ 流通股本 > 10% 命中 |
| 存货 / 应收财务疑点 | F10 三大报表 | 存货、应收增速与营收增速对比，最新季报同比 |
| 股息率（TTM） | 东财 F10「分红融资」 | 近 12 个月每股现金分红合计 ÷ 现价 |
| 连续派息年数 | F10 分红明细 | 连续现金分红年数（送股转增不计） |
| 分红覆盖倍数 | F10 现金流量表 | 经营活动现金流净额 ÷ 年度分红总额 |
| 分红率 | F10 分红明细 | 年度分红总额 ÷ 归母净利润；> 80% 警惕 |
| 定期报告预约披露日 | 巨潮「预约披露」栏目 / 东财 F10 | 财报窗口禁开仓的起算依据，每季初核对更新 |
