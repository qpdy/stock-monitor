# 策略层：长线红利仓

> **定位**：收息 + 防御的压舱石。赚股息的钱（+ 顺带的估值修复），收益预期 = 股息率 4%~6%，**不预期赚价差**。持有周期以年计。
>
> **额度**：总资金 **≤ 30%**，单票 ≤ min(15%, 2% ÷ 止损幅度)（止损 -15% 时 ≈ 13%）。
>
> 通用纪律见 [trading-common.md](trading-common.md)，本文只写本层特有内容与参数覆盖。

---

## 〇、本层与中线层的参数差异总览

| 参数 | 中线逻辑仓 | 长线红利仓 | 为什么不同 |
|---|---|---|---|
| 硬止损 | -8% ~ -10% | **-15% 兜底** | 红利股波动低但也不是零波动，-8% 会被日常波动打掉；本层真正的卖出信号是股息逻辑，价格止损只是尾部兜底 |
| 时间止损 | 13 周不涨即换 | **不适用，改年度检视** | 纯吃息不看涨幅——价格不涨但股息照发，持有逻辑就成立；用 13 周检视会在除息震荡里反复误杀 |
| 财报窗口 | 披露前一周禁开仓 | **不适用** | 长线必须跨财报，窗口禁令与持有周期矛盾；替代：年报后强制重跑排雷 |
| 检视频率 | 季度重检 | **年度检视（年报分红方案为节点）+ 季度轻检** | 分红逻辑按年演进；季度只看排雷命中（通用第六节），不看分红趋势 |
| 连败触发 | 3 笔 / 冻结一周 | **2 笔 / 冻结一个月** | 本层止损极罕见（逻辑破坏才触发），出现两次说明选股标准有系统性问题，一个月是重检选股标准的最短周期 |
| 复盘 | 滚动 20 笔 | **年度复盘** | 年成交仅几笔，滚动窗口统计上无意义 |

## 一、选股纪律（买入前全部满足，缺一不买）

### 1.1 逻辑纪律

- **一句话测试**：买入前必须写清——**当前股息率多少、分红靠什么覆盖（经营现金流 / 自由现金流）、凭什么可持续**。说不清现金流来源的股息 = 不可信的股息。

### 1.2 硬性选股条件

- [ ] **股息率（TTM）≥ 5%** 才允许首笔买入（本层的"不追高"：股息率就是本层的估值尺，价格越贵股息率越低）
- [ ] **连续派息 ≥ 5 年**（穿越过至少一轮完整周期）
- [ ] **分红覆盖 ≥ 1.5 倍**（经营现金流 / 年度分红总额，防借钱分红、防不可持续）
- [ ] 排雷七项全跑（同中线层 2.2 清单），另加一条：**分红率 > 80% 的警惕**（利润几乎全分掉，没有再投资与缓冲空间，除非现金流极其稳定）

### 1.3 买入行为纪律

- **股息率阶梯建仓（两档）**：首笔在股息率 ≥ 5% 时买入计划仓位的 1/2；股息率再上 0.5%（即价格更便宜，约 -9%）买第二笔 1/2，共 2 笔。股息率不到下一档 = 加仓条件不满足，等。
- **止损优先于加仓**：价格先触及止损线时，按止损整票清仓、阶梯作废。约束：加仓档位必须始终位于止损线之前（第二档约 -9%，远在 -15% 之前）——档位若落在止损线之后，该档永远等不到触发（先被止损清出），形同虚设。
- **每笔加仓前重检一次分红逻辑**（最新财报现金流有没有恶化），不是无脑挂单。

> **与"禁止摊成本"的关系**：通用黑名单第 2 条禁止的是**计划外**的亏损补仓。本层的阶梯建仓是**买入前就写死**的计划——触发条件是股息率阈值（估值更便宜），不是"亏了想回本"；且每笔之间有逻辑重检。这是通用文档"原计划就含分批"条款的直接应用，不构成违纪。

## 二、卖出纪律（本层的核心：卖点是逻辑变化，不是价格）

| 纪律 | 规则 | 作用 |
|---|---|---|
| 逻辑止损 | **分红覆盖跌破 1 / 排雷命中 / 戴帽 ST** → 无条件走（分红削减的处置归下行年度检视，不在本行） | 股息逻辑死亡 = 持有理由消失 |
| 年度检视 | 年报分红方案公布后检视：**连续两个分红年度下降 → 离场**（第一年下降时减半示警） | 允许单年波动，不给连续恶化的票"再看一年"的惯性 |
| 估值止盈 | **股息率跌破 3% → 减半；继续跌破 2.5% → 清仓**，等待下一轮 5% | 本层唯一止盈条件——"目标价的股息版"，防止好的收息股拿成贵的价差股 |
| 硬止损 | **加权成本价** -15%（基准见通用五），触发当日必走 | 尾部兜底：跌 15% 而股息逻辑尚存的情况要复盘（可能分红尚未年报确认，价格先跌 = 市场在提前定价分红削减），但纪律先走，复盘后逻辑确认完好可重新走选股流程买回——这是**新决策**，不是"止损价到了不走"的例外 |

- 跌停预案、条件单机制按通用文档第五节执行（红利股波动低，但预案必须有——尾部风险不挑策略层）。

## 三、持有中纪律

- **年度重检**：每年年报后重跑 1.2 全部清单（含排雷七项），任一命中 → 逻辑止损。
- **季度轻检**：通用第六节的季度重检在本层照常执行（只查排雷命中，不查分红趋势）。
- **除息不动**：除权除息日的价格跳空不是下跌，不做任何操作；分红到账默认再投入（投入时重新过当时点的选股条件，不强制买回原票）。
- **区分两种跌**：通用第六节照常适用——红利股跟着高股息板块整体回撤（如利率上行周期）不是卖出理由；独立于板块的跌才触发重检。

## 四、连败参数（覆盖通用默认）

触发：连续 **2 笔**计划内亏损平仓（含硬止损、逻辑止损、年度检视离场；计数规则同通用）。

1. **立即**：冻结本层新买入**一个月**，期间重检选股标准（重点：是不是系统性买入了"高股息陷阱"——周期顶利润、借钱分红）。
2. **解冻后**：本层额度减半（30% → 15%），一笔计划内盈利平仓（含估值止盈）后恢复。

## 五、复盘参数

- **年度复盘**（每年 1 月，覆盖上一完整年度）：
  - 本层股息收益合计 vs 违纪次数 vs 止损损失；
  - 每笔离场必归因：逻辑止损 / 年度检视 / 估值止盈 / 硬止损 / 违纪；
  - 硬止损笔数 > 1 → 选股条件是否需要加严（如股息率门槛 5% → 6%）。
- 不做滚动窗口期望值统计（样本不足）；"停用本层"由年度复盘决议，而非统计触发。
