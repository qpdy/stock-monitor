# 治理：参数、绩效、变更与系统联动

> **定位**：让体系可审计。纪律条款回答"怎么做"，本文回答三件事——**每个数字从哪来**（参数台账）、**做得好不好怎么衡量**（基准与归因）、**纪律怎么被检查**（执行属性与周报）。行为本身的对错由 [trading-common.md](trading-common.md) 管，本文不管行为，管证据。
>
> 版本管理：docs 全目录随仓库 git 管理，参数变更必有 commit 记录；文档即版本，不另设版本号。

## 一、参数台账

> 原则：**文档中每一个定量参数，必须登记其依据；依据分三类，如实标注，不冒充**：
> ① **推导**——由体系内其他参数算术推出（如组合在险 10% = 5 只 × 2% 满配）；
> ② **结构性**——绑定市场结构，非数值拟合（如时间止损 13 周 = 一个财报季）；
> ③ **惯例默认（待复核）**——无本地数据前的保守锚点，复核周期内用本体系逐笔数据验证或修正。
>
> 三类皆无的参数不允许存在于文档中。

### 1.2 恢复条件算术（总闸的已知代价，写透）

回撤 15% 触发时资产约 85（高点计 100），恢复需回到 92（回撤 ≤8%），即总资产 **+8.2%**。此时已降至半仓，市场涨 x%、总资产约涨 0.5x%——恢复实际要求**市场自低点反弹约 16%**。代价：V 型反转的最陡一段结构性踏空；换来：慢熊中强制降敞口、恢复须过周末复盘双重闸。两端不可兼得，取后者的理由：**个人的生存优先于反弹的收益**。此算术不接受"下次反弹快点恢复"式的临时修改——那是把总闸改成总闸的形状但不剩总闸的功能。

### 1.3 参数变更流程

1. 变更只能**盘后**提出、书面登记：日期 / 条款 / 旧值 → 新值 / 理由 / 触发背景。
2. **冷静期**：提议与生效之间强制间隔 **≥ 3 个交易日**。持仓期间为迁就当前持仓的变更禁止（通用文档既有原则，此处给流程落地）。
3. 生效即更新台账复核列，并留 git commit 记录。

### 1.4 存量层回溯审计（一次性）

三层均为原生层，未经新层准入的"模拟 ≥ 20 笔期望值非负"检验（discipline 四节）——同一把尺对存量同样有效，只是改用回溯补考。一次性动作：用近 1~2 年券商交割单回填三层逐笔记录（净值口径，载体见第三节 `trades/`），产出各层胜率、期望值、短线噪声止损率、中线"止损后不收回"比例，据此将台账"惯例默认"类参数升格或修正。回溯完成前，全部"待复核"参数按现值执行；回溯结果与现参数冲突的，走 1.3 流程一次改到位，不逐条临时改。

## 二、基准与绩效归因

### 2.1 各层基准

| 层 | 基准 | 理由 |
|---|---|---|
| 中线 | 沪深 300 全收益 | 主力层的机会成本是"直接持有市场"——跑不赢 = 担了个股风险没拿到超额 |
| 长线 | 中证红利全收益 | 同类可比：跑输红利指数的红利仓没有存在价值 |
| 短线 | 0（绝对收益） | 天级持有，指数基准无意义；门槛线 = 资金机会成本（逆回购年化） |

### 2.2 归因方法（每笔，随复盘录入）

- **beta 部分** = 持有期基准区间涨幅 × 该笔平均资金占用；**alpha = 实际盈亏 − beta 部分**。
- 滚动统计各层 **alpha 占比**：持续 < 50% = 在赚指数的钱、担个股的风险——比"期望值 < 0"更早触发的降额度信号（处置见 2.4）。
- **市值风格披露**：季报记录持仓流通市值中位数，与沪深 300 成分中位数对照；持仓显著偏中小盘时，中线层跑输基准的判定须注明风格口径（与 regime 的中证 1000 对照同源，portfolio-risk 五节）——风格错配的"跑输"是基准问题，不是选股问题，减半处置前先看这一行。

### 2.3 短线噪声止损率（专项统计）

- 定义：止损平仓后 **3 个交易日内**收盘价收回止损价上方 → 记一次噪声止损。
- 用途：验证 -3%~-5% 区间是否被日常波动无意义地打掉。连续两个季度噪声止损率 > 50% → 止损区间整体上移一档（走 1.3 变更流程），同时优先收窄的是"低吸时点"，不是放松纪律。

### 2.4 风险调整指标与层级处置（季报）

- **卡玛比率** = 年化收益 ÷ 期间最大回撤（各层一张、总账一张）。个人非满仓节奏下比夏普更真实——它直接回答"每承受 1 单位回撤换来多少收益"。
- **跑输处置**：连续 **2 个季度**跑输本层基准 → 该层额度减半（规模管理思维：机构对 AUM 的分配，不是"砍层"二元处置）；此后一个季度跑赢即复位。短线层不适用（绝对收益基准），由期望值与双窗口停用机制管辖。
- **减半类处置不叠乘（统一规则）**：本体系所有"额度减半"类处置——连败解冻减半（通用四节）、滚动窗口期望值 / alpha 占比减半（通用七节）、跑输基准减半（本节）——**互不叠乘，取当前生效的最严一处**；各自的解除条件独立跟踪，全部解除后额度复位。防"多重原因连环减半到 1/4、1/8"的过度惩罚。regime 防御档系数不属于减半处置，是档位调节，独立生效于额度上限。

### 2.5 闲置资金

- 冻结期、等待期、防御档压缩出的资金默认**国债逆回购**（R-001 / GC001）或场内货基；周五与节前留意计息规则。
- 纪律含义：闲置资金有默认去处，防"钱躺在账户里就手痒买点什么"。

### 2.6 统计口径与功率（所有滚动统计的前提）

- **净值口径（总则）**：本体系全部盈亏、期望值、alpha / beta、胜率统计，一律按净收益计——扣除佣金、印花税、过户费、滑点（长线层另含红利税，见其文档三节）。毛收益口径的期望值系统性虚高，短线层尤甚（年摩擦 ≈ 往返笔数 × 0.13%，见台账）。
- **窗口功率（已知噪声）**：滚动窗口期望值的标准误 ≈ 单笔收益标准差 ÷ √笔数——20 笔窗口约 1%、50 笔窗口约 0.7%。含义：真实期望 +0.5% 的合格策略，单窗口测得为负的概率约三成——**单窗口期望值 < 0 的降半仓假阳性不低**，保留单窗口触发是"处置温和、误伤成本低"的取舍（停用须双窗口确认，正是为此设防）。50 笔双窗口按短线层频次约需两年——停用机制实为两年尺度，属已知属性而非缺陷；调参须在此噪声背景下判断，不以单窗口读数定生死。

## 三、执行属性与系统联动（文档 ↔ stock-monitor）

> 目标：纪律从"我记得"变成"系统替我记着"。每条可检查的纪律标注三类属性之一；**标注是目标状态，不虚报现状**——未接入的 [系统] 项标注"待接入"，落地前按 [半自动] 执行。

| 属性 | 含义 | 主要条款（映射示例） |
|---|---|---|
| [系统] | stock-monitor 监控并推送 | 止损单在挂状态、各层额度、回撤水位、组合在险额、regime 档位与切换倒计时、财报窗口日历、每日合规快照 |
| [半自动] | 系统提醒 + 人工执行 | 条件单挂单、解禁/减持提醒、压力测试季度执行、参数复核到期提醒 |
| [人工] | 只能人来 | 投资备忘录撰写、周末复盘与周报、参数变更、违纪认定 |

- **每日合规快照**（收盘后，[系统]）：回撤水位、regime 档位、各层暴露 vs 额度、行业分布、组合在险额 vs 10%、止损单在挂核对、明日财报窗口提示。
- **归档**：投资备忘录存仓库 `memos/`（每票一份，票名+日期命名）；周报 / 季报 / 压力测试记录存 `reviews/`（按 `YYYY-WW` / `YYYY-Qn` 命名）；逐笔交易记录存 `trades/`（CSV，每笔一行，字段见附录 C）。三者随 git 版本化——归档即审计轨迹，散落在聊天记录或脑袋里等于没存。
- **交割单对账（每月）**：`trades/` 每月与券商交割单核对一次，漏录当月补齐，季报"记录完整性"项计数。交割单是唯一不可篡改源，两边不符以交割单为准——选择性记录（赚的记得清、亏的忘得快）是复盘统计最大的失真源，对账是它的唯一解药。
- 映射表未尽条款默认 [人工]；升格为 [系统] 的顺序按"违反后果严重度 × 检查频率"排——止损单在挂与组合在险优先。
- 未接入项集中在每日快照里做人工日报替代，直到系统覆盖。

## 四、周报模板（周末复盘的输出格式，替代原"四步"清单）

1. **合规**：黑名单 14 条逐项过（持续状态型 1/8/11/12/13/14 重点）；止损单在挂核对结果。
2. **组合风险快照**：回撤水位与恢复条件进度；regime 档位；各层暴露 vs 额度（含额度浮盈超限跟踪）；行业分布 vs 30%（含被动超限跟踪）；组合在险额 vs 10%（成本锁定口径）。
3. **绩效**：本周各层盈亏与 alpha/beta 归因；滚动窗口期望值；短线噪声止损率。
4. **计划**：下周计划内操作清单（计划分批、到期的条件动作）——盘中只执行清单、不新增。
5. **异常与待办**：压力测试 / 参数复核到期提醒；[系统] 项待接入清单的推进。

## 五、季报模板

1. 分层绩效 vs 基准：跑赢 / 跑输判定，连续 2 季跑输处置检查（2.4）。
2. 卡玛比率：各层 + 总账。
3. 压力测试三情景结果与结构建议（portfolio-risk 第四节）。
4. 参数台账复核：到期参数逐项过，"惯例默认"类优先用本地数据升格或修正。
5. 违纪统计与行为趋势：违纪占比（≥10 笔后）、类型集中度、当季变更记录回顾。
6. 记录完整性：各月交割单核对结果、漏录补齐计数（第三节）。

## 六、防膨胀总则

- **准入**：新增任何纪律条款，必须同时指明执行时点 + 检查手段（[系统] / [半自动] / [人工]）。指不出 = 不收录。
- **退出**：每年年度复盘删一次条款——连续 4 个季度未被触发、未被引用、无检查手段的条款，删除或合并。**条款数量是体系的执行成本，不是资产**：一套记不住的顶级体系不如一套记得住的合格体系。

## 附录 C：`trades/` 逐笔记录字段（CSV 表头）

> 通用文档第七节全部统计（期望值、alpha / beta、噪声止损率、连败计数）与周报 / 季报的数据源。每笔交易一行：买入时建行填前 11 列，平仓时补全其余；短线层另填末 2 列，中长线留空。字段够用即可，不加列——想加列时，先问哪个统计消费它。

