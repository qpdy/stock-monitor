# 策略层：中线逻辑仓

> **定位**：本组合的主力层。赚三种钱——分红的钱 / 业绩增长的钱 / 事件催化的钱，持有周期以周~月计（时间止损 13 周）。
>
> **额度**：总资金的余额（短线仓 ≤ 10% + 长线红利仓 ≤ 30% 之外的余量，通常 60%~80%）。
>
> 通用纪律（风险预算、总回撤线、卖出执行、情绪、复盘框架、黑名单）见 [trading-common.md](trading-common.md)，本文只写本层特有内容与参数覆盖。

---

## 一、层内仓位纪律

- **持股数量 5~8 只，跨行业**——这是自己拼的"指数"，用组合分散代替指数保护。
- 单票仓位上限按通用公式：**min(25%, 2% ÷ 止损幅度)**，止损取 -8% ~ -10%，对应上限 20%~25%。

## 二、买入前纪律

### 2.1 逻辑纪律

- **一句话测试**：买入前必须能用一两句话说清"买它赚的是什么钱"，本层合法清单封闭为三种：
  - 分红的钱（股息可持续且当前被低估）
  - 业绩增长的钱（景气上行、业绩超预期）
  - 事件催化的钱（并购重组、政策落地、产品涨价）
  - 说不出来、或属于其他类别（如"它会涨停"）→ 不属于本层，不买。
- **计划先行**：买入前写死三件事——目标价或兑现条件、止损价、持有周期。盘中不临时改。

### 2.2 排雷纪律（一票否决，任一命中不买；本层七项全跑）

- [ ] 质押率 > 50% 的不碰
- [ ] 商誉 / 净资产占比过高（> 30%）的不碰
- [ ] 被证监会立案调查、审计非标意见的不碰
- [ ] 连续亏损逼近退市新规红线的不碰
- [ ] 大股东近期公告减持计划的不碰
- [ ] 临近大额限售解禁（解禁量 > 流通盘 10% 且在 3 个月内）的不碰
- [ ] 存货、应收账款增速远超营收增速（财务疑点）的不碰

### 2.3 买入行为纪律

- **分批建仓**：任何买入至少分 2~3 笔，间隔至少一个交易日，不一把梭。
- **不追高**：当日已涨 ≥ 5% 不追买入；涨停板打开的票当天不碰。
- **财报窗口谨慎**：业绩预告 / 年报季报披露前一周内，不开新仓（防预告变脸）。

## 三、卖出纪律（事前写死，触发必走）

| 纪律 | 规则 | 作用 |
|---|---|---|
| 硬止损 | **加权成本价** -8% ~ -10%（基准见通用五），触发当日必走，不等反弹 | 防归零、防深套 |
| 逻辑止损 | 分红砍了 / 业绩连跌 3 季 / 立案调查 / 戴帽 ST → 无条件走，不看成本价 | 防"价值陷阱"死扛 |
| 兑现止盈 | 逻辑兑现（利好落地 / 涨幅达标）→ 分批走，不贪最后一段 | 防坐电梯 |
| 时间止损 | **自首笔成交日起算 13 周**既不涨、逻辑也未演进 → 换股（首笔起算，防无限拖延建仓） | 防资金躺死在横盘股 |

**卖出执行细则**（条件单、跌停预案、集合竞价）全部按通用文档第五节执行，此处不重复。

- **分批止盈**：达到第一目标位卖 1/2，剩余按最高点回撤 8% 跟踪止盈（固定参数，不改）。

## 四、持有中纪律

- **禁止摊成本**：按通用文档第六节——只有"逻辑没变、只是价格更便宜、且原计划就含分批"才允许按计划买下一笔。
- **季度重检**：每季度财报后重跑 2.2 排雷清单，任一命中 → 逻辑止损。

## 五、连败参数（覆盖通用默认）

采用通用默认：连续 **3 笔**计划内亏损平仓 → 冻结本层买入**一周** → 恢复后本层仓位上限减半，一笔计划内盈利平仓解除。

## 六、复盘参数

- 滚动窗口：**20 笔**（按笔数，不按月——月度样本只有几笔，统计上不足以下结论，易误杀）。
- 期望值连续两个不重叠窗口 < 0 → 停用本层（通用文档第七节）。

## 附：本层交易检查卡（买入前逐项打勾）

```
□ 一句话说清赚什么钱（分红 / 业绩 / 事件 三选一）
□ 排雷清单 7 项全过
□ 目标价 / 兑现条件已写
□ 止损价已写（-8%~-10%）
□ 仓位合规：单票 ≤ min(25%, 2%÷止损幅度)，本笔委托风险 ≤ 1%
□ 券商条件单已挂（或 stock-monitor 止损监控已录入）
□ 跌停预案已知悉（次日集合竞价挂跌停价卖出）
□ 不在财报披露窗口内（披露前一周）
□ 当日涨幅 < 5%，且当日无止损发生（冻结日不买）
□ 分批计划：本笔是第几笔 / 共几笔（时间止损自首笔起算）
□ 记录已登记（买入即录入复盘表，标记策略层=中线）
```
