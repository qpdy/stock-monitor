# 策略层：短线仓（题材 / 事件）

> **定位**："学费 + 彩票"，赚情绪发酵的钱。赚了是惊喜，亏了不影响大局。
>
> **额度**：总资金 **≤ 10%**，单票 ≤ 5%。禁止层间额度挪用（亏了不能"先用中线额度顶着"）。
>
> **风格锁定：只做低吸潜伏型**——在题材发酵前/初段买入，等资金抬轿。不做打板、不做接力、不做追涨（通用黑名单第 4 条管辖，本层无豁免）。
>
> 通用纪律见 [trading-common.md](trading-common.md)，本文只写本层特有内容与参数覆盖。

---

## 〇、本层与中线层的参数差异总览

| 参数 | 中线逻辑仓 | 短线仓 | 为什么不同 |
|---|---|---|---|
| 硬止损 | -8% ~ -10% | **-3% ~ -5%** | 题材证伪速度快，深止损等于把彩票拿成股东 |
| 时间止损 | 13 周 | **3~5 个交易日** | 短线的逻辑就是几天内兑现，不兑现即证伪 |
| 排雷 | 七项全跑一票否决 | **硬排雷 2 项 + 知情项 5 项** | 题材股常命中质押/商誉等基本面项，全跑则无票可买；但立案/退市红线是物理风险（连续跌停出不来），不可降级 |
| 财报窗口 | 披露前一周禁开仓 | **披露前一日禁开仓** | 持有仅 3~5 个交易日，开仓端只需防"明天就披露"；存量持仓跨披露日的处理见 1.3 |
| 建仓 | 2~3 笔、间隔 ≥1 交易日 | **≤ 2 笔、当日或次日建完** | 短线节奏快，隔日分批等来的常常是错过 |
| 连败触发 | 3 笔 / 冻结一周 | **5 笔 / 冻结 3 个交易日** | 短线胜率低是常态（可能仅 40%），连 3 笔止损是高频事件而非警报；且一周冻结等于停做半个月，惩罚与行为不匹配 |
| 复盘窗口 | 滚动 20 笔 | **滚动 50 笔** | 笔数多、周期短，20 笔窗口滚动太快，统计噪声大 |

## 一、买入前纪律

### 1.1 逻辑纪律

- **一句话测试**：买入前必须写清三件事——**什么题材、什么催化、预期几个交易日兑现**（例："设备更新政策细则本周落地，工程机械板块尚未启动，预期 3~5 天"）。催化没有明确日期的（"早晚会涨"）= 说不清楚 = 不买。
- **只低吸**：买入时该票当日涨幅 < 5%，且所属板块尚未进入主升（板块单日涨幅居前、集体涨停的属于"发酵后段"，不碰）。**宁可错过，不做接力。**

### 1.2 排雷纪律

**硬排雷（一票否决）**：

- [ ] 被证监会立案调查、审计非标意见的不碰
- [ ] 连续亏损逼近退市新规红线的不碰（含已戴帽 / 逼近戴帽）

**知情项（不否决，但买入记录里须写明"已知"）**：

- 质押率 > 50% / 商誉占比 > 30% / 大股东减持计划 / 3 个月内大额解禁 / 存货应收财务疑点

> 知情项的含义：短线赚情绪的钱，不管基本面，这些瑕疵不阻止买入；但它们决定**止损必须无条件执行**——有瑕疵的票证伪时跌起来没有基本面承接，"-5% 走人"没有任何商量余地。写"已知"是为了复盘时能回答"这笔亏损是否源于我明知的风险"。

### 1.3 买入行为纪律

- **建仓 ≤ 2 笔**：当日 1 笔，最多次日补 1 笔，不拖到第三天。
- **财报窗口**：业绩预告 / 定期报告披露前一日内，不开新仓。**存量持仓跨披露日不做特殊处理**：止损 / 止盈 / 时间止损照常执行，披露本身不构成盘中新决策（通用第六节"盘中只执行"）；披露落地即催化兑现或证伪，走既定卖出通道。
- **止损单与买入同时挂**：通用文档要求"止损单当天就挂好"，本层加严——**买入委托和止损条件单同时下**，不留"先看看"的空档。

## 二、卖出纪律（事前写死，触发必走）

| 纪律 | 规则 | 作用 |
|---|---|---|
| 硬止损 | **加权成本价** -3% ~ -5%（建仓时写死取值，基准见通用五），触发当日必走 | 题材证伪的第一信号是价格，先走再想 |
| 时间止损 | 买入后 **3~5 个交易日**（建仓时写死天数）催化未兑现 → 无条件走 | 短线没有"逻辑演进"，只有"兑现"和"证伪" |
| 兑现止盈 | 催化落地 / 涨幅达标（如 +10%~15%）→ **一次性了结，不分批** | 金额小，分批的摩擦成本与跟踪成本大于收益 |
| 意外涨停 | 持有中涨停 → **开板即当日卖出**；收盘仍封死 → **次日不板即走**（固定规则，盘中无需决定，落袋优先） | 短线仓吃不到龙头的完整涨幅，那是接力玩家的事 |

- **T+1 补充（买入当日涨停）**：当日涨停但 T+1 无法卖出的（无论收盘开板与否），次日统一按"**不板即走**"执行——开盘不涨停即卖；次日仍封死则继续顺延同一规则。买入当日触发止损的，按通用文档第五节 T+1 条款执行。
- 跌停预案按通用文档第五节执行。本层特别强调：**知情项票的跌停预案没有"等开板"选项之外的任何选项**——收盘未成交，次日 9:15 集合竞价挂跌停价卖出，不改单。

## 三、持有中纪律

- **不加仓超过第 2 笔**：短线没有"计划内分批摊薄"，只有建仓期的第 2 笔。
- **盘中只执行**：本层最大的违纪温床是盘中看分时后"改主意"——所有卖出判断在建仓时已写死，盘中不做新决策（通用文档第六节）。

## 四、连败参数（覆盖通用默认）

触发：连续 **5 笔**计划内亏损平仓（硬止损、时间止损均算；计数规则同通用：计划内盈利平仓重置，平手不计数，违纪交易不计入但违纪盈利不重置）。

1. **立即**：冻结本层新买入 **3 个交易日**（已挂条件单照常执行）。
2. **解冻后**：本层额度减半（10% → 5%），一笔计划内盈利平仓后恢复。
3. **跨层升级**：与中线/长线层同时触发时，按通用文档第四节执行全局冻结。

## 五、复盘参数

- 滚动窗口：**50 笔**，独立于其他层统计。
- 额外必录字段：**买入时板块所处阶段**（发酵前 / 初段 / 后段）——用于验证"只低吸"是否真的执行，以及低吸时点的胜率差异。
- 期望值连续两个不重叠 50 笔窗口 < 0 → 停用本层（学费交够了，停止交学费）。

## 附：本层交易检查卡（买入前逐项打勾）

```
□ 一句话已写清：什么题材 / 什么催化 / 预期几天兑现（催化有明确日期）
□ 硬排雷 2 项全过（立案调查 / 退市红线）
□ 知情项已标记"已知"（质押 / 商誉 / 减持 / 解禁 / 财务疑点）
□ 止损价已写（-3%~-5%），条件单与买入委托同时下
□ 时间止损天数已写（3~5 日）
□ 当日涨幅 < 5%，板块未处于发酵后段
□ 明日无业绩披露
□ 建仓计划：本笔是第 1 / 2 笔
□ 仓位合规：单票 ≤ 5%，本层总额 ≤ 10%
□ 当日无止损发生（冻结日不买）
□ 记录已登记（标记策略层=短线 + 板块阶段）
```
