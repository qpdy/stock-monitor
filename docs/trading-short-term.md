# 策略层：短线仓（题材 / 事件）+ 做T子模式（高频日内层）

> **短线仓定位**："学费 + 彩票"，赚情绪发酵的钱。赚了是惊喜，亏了不影响大局。
>
> **短线仓额度**：总资金 **≤ 10%**，单票 ≤ 5%。禁止层间额度挪用（亏了不能"先用中线额度顶着"）。
>
> **风格锁定：只做低吸潜伏型**——在题材发酵前/初段买入，等资金抬轿。不做打板、不做接力、不做追涨（通用黑名单第 4 条管辖，本层无豁免）。
>
> **做T子模式定位**：赚**日内振幅 + 隔日情绪接力**的钱，作为短线仓内的高频日内子层运营——与短线仓共用 ≤ 10% 额度、不突破短线层上限；具体边界、战法、纪律见本文第四节。
>
> 通用纪律见 [trading-common.md](trading-common.md)，本文只写本层特有内容与参数覆盖。

## 〇、本层与中线层的参数差异总览

| 参数 | 中线逻辑仓 | 短线仓 | 做T子模式（短线仓内） | 为什么不同 |
|---|---|---|---|---|
| 硬止损 | -8% ~ -10% | **-3% ~ -5%** | **-0.5% ~ -1%** | 做T单笔金额大（≥ 5000 元）+ 高频，-3% 已吃掉单笔目标差价的 1.5 倍以上；日内波动核心区必须更窄 |
| 时间止损 | 13 周 | **3~5 个交易日** | **1~3 个交易日（含当日强制平仓）** | 做T吃日内/隔日的钱，跨夜风险是首要规避敞口；最长持仓 1~3 天 |
| 排雷 | 七项全跑一票否决 | **硬排雷 3 项 + 知情项 5 项** | **沿用短线硬排雷 3 项** | 做T短周期持有、基本面风险概率低，硬排雷覆盖即可 |
| 财报窗口 | 披露前一周禁开仓 | **披露前一日禁开仓** | **披露前一日禁开仓**（与短线同） | 同短线仓处理 |
| 建仓 | 2~3 笔、间隔 ≥1 交易日 | **≤ 2 笔、当日或次日建完** | **≤ 2 笔、当日或次日建完**（与短线同） | 同短线仓 |
| 流动性门槛 | ADV ≥ 5000 万、市值 ≥ 50 亿 | **ADV ≥ 1 亿、市值 ≥ 30 亿** | **ADV ≥ 5 亿** | 做T进出场快、止损窄，5 亿才给 -0.5%~-1% 止损的成交空间；不另设市值下限（高成交额自动排斥微盘） |
| 连败触发 | 3 笔 / 冻结一周 | **5 笔 / 冻结 3 个交易日** | **2 次 / 冻结 1~3 天** | 做T频次高（每周 5~10 笔），5 次才停等于无监督；2 次即冻 |
| 复盘窗口 | 滚动 20 笔 | **滚动 50 笔** | **滚动 50 笔**（独立统计） | 做T频次与短线同；独立统计战法维度的胜率差 |
| 单笔最小金额 | — | — | **≥ 5000 元** | < 5000 元按最低 0.5 元/笔佣金失效（详见 4.4 佣金条件） |

## 一、买入前纪律

### 1.1 逻辑纪律

- **一句话测试**：买入前必须写清三件事——**什么题材、什么催化、预期几个交易日兑现**（例："设备更新政策细则本周落地，工程机械板块尚未启动，预期 3~5 天"）。催化没有明确日期的（"早晚会涨"）= 说不清楚 = 不买。
- **只低吸**：买入时该票当日涨幅 < 5%，且所属板块尚未进入主升（板块单日涨幅居前、集体涨停的属于"发酵后段"，不碰）。**宁可错过，不做接力。**

### 1.2 排雷纪律

**硬排雷（一票否决）**：

- [ ] 被证监会立案调查、审计非标意见的不碰
- [ ] 连续亏损逼近退市新规红线的不碰（含已戴帽 / 逼近戴帽）
- [ ] 流动性不达标的不碰：20 日 ADV < 1 亿或流通市值 < 30 亿（portfolio-risk 三节——对题材票这是与立案同等地位的硬项：出口没有，止损白挂）

**知情项（不否决，但买入记录里须写明"已知"）**：

- 质押率 > 50% / 商誉占比 > 30% / 大股东减持计划 / 3 个月内大额解禁 / 存货应收财务疑点

> 知情项的含义：短线赚情绪的钱，不管基本面，这些瑕疵不阻止买入；但它们决定**止损必须无条件执行**——有瑕疵的票证伪时跌起来没有基本面承接，"-5% 走人"没有任何商量余地。写"已知"是为了复盘时能回答"这笔亏损是否源于我明知的风险"。

### 1.3 买入行为纪律

- **建仓 ≤ 2 笔**：当日 1 笔，最多次日补 1 笔，不拖到第三天。
- **财报窗口**：业绩预告 / 定期报告披露前一日内，不开新仓。**存量持仓跨披露日不做特殊处理**：止损 / 止盈 / 时间止损照常执行，披露本身不构成盘中新决策（通用第六节"盘中只执行"）；披露落地即催化兑现或证伪，走既定卖出通道。
- **止损单与买入同时挂**：通用文档要求"止损单当天就挂好"，本层加严——**买入委托和止损条件单同时下**，不留"先看看"的空档。

## 二、卖出纪律（事前写死，触发必走）

| 纪律 | 规则 | 作用 |
|---|---|---|
| 硬止损 | **加权成本价** -3% ~ -5%（建仓时写死取值，基准见通用五），触发当日必走 | 题材证伪的第一信号是价格，先走再想 |
| 时间止损 | 买入后 **3~5 个交易日**（建仓时写死天数）催化未兑现 → 无条件走 | 短线没有"逻辑演进"，只有"兑现"和"证伪" |
| 兑现止盈 | 催化落地 / 涨幅达标（如 +10%~15%）→ **一次性了结，不分批** | 金额小，分批的摩擦成本与跟踪成本大于收益 |
| 意外涨停 | 持有中涨停 → **开板即当日卖出**；收盘仍封死 → **次日不板即走**（固定规则，盘中无需决定，落袋优先） | 短线仓吃不到龙头的完整涨幅，那是接力玩家的事 |

- **T+1 补充（买入当日涨停）**：当日涨停但 T+1 无法卖出的（无论收盘开板与否），次日统一按"**不板即走**"执行——开盘不涨停即卖；次日仍封死则继续顺延同一规则。买入当日触发止损的，按通用文档第五节 T+1 条款执行。
- 跌停预案按通用文档第五节执行。本层特别强调：**知情项票的跌停预案没有"等开板"选项之外的任何选项**——收盘未成交，次日 9:15 集合竞价挂跌停价卖出，不改单。

## 三、持有中纪律

- **不加仓超过第 2 笔**：短线没有"计划内分批摊薄"，只有建仓期的第 2 笔。
- **盘中只执行**：本层最大的违纪温床是盘中看分时后"改主意"——所有卖出判断在建仓时已写死，盘中不做新决策（通用文档第六节）。

## 四、做T子模式（短线仓内的高频日内层）

> **定位**：赚**日内振幅 + 隔日情绪接力**的钱。**所有纪律参数比短线仓更严一档**——做T标的波动大、止损窄、连败频次天然更高。
>
> **风格锁定：当日闭环优先**。买入即设退出计划，当日达目标差价必走、未达且浮亏 0.5%~1% 必走；不达预期不跨夜——隔夜风险是本子模式首要规避敞口。
>
> **与 discipline 三节"被排除的策略"的关系**：彼处排除的"T+0 日内回转"指**给存量持仓降成本的执行技巧**（同票 T+0），属通用黑名单第 2 条管辖；本子模式是**独立的做T仓**（不同票、当日闭环、不与底仓混），不在被排除之列——见 [trading-discipline.md](trading-discipline.md) 第三节注解。

### 4.1 定位与边界

**赚什么钱**：

- 隔夜跳空 + 开盘冲高 / 低开回补（战法 A 尾盘买入次日卖）
- 主线龙头缩量回调后的反弹（战法 B 强势股低吸）
- 板块集体启动时的龙头突破（战法 C 趋势突破）
- 日内振幅 ≥ 3% 标的的高抛低吸（做T战法核心）

**不赚什么钱**：

- 隔夜消息博弈 / 一字板连板接力（黑名单第 4 条）
- 给底仓降成本（discipline 三节排除的"日内回转"，本子模式不为此类）
- 网格机械摊薄（黑名单第 2 条）

**额度边界**：

- 本子模式与短线仓**共用 ≤ 10%** 总资金额度（通用第二节 + discipline 第二节）——本体系不允许做T突破短线层上限。
- 单笔最小金额 **≥ 5000 元**——低于此按最低 0.5 元/笔佣金失效，往返成本 + 印花税 > 目标差价，做 T 无经济意义（详见 4.4 佣金条件）。
- 本子模式自身上限 ≤ 短线层额度的 50%（即 ≤ 总资金 5%）——避免做 T 把短线额度打满、失去原短线仓的题材低吸空间。

**持仓周期**：

- **当日闭环（强约束）**：90% 的做 T 仓当日买入当日卖出；剩余 10% 仅"战法 A 尾盘买入次日卖"明确写入计划才允许跨夜 1 天。
- **最长持仓 1~3 个交易日**——超过 3 天未了结视为仓位失控，按纪律强制了结（不是"止损"也不是"止盈"，是"管理失败"，按时间止损 1~3 日上限走）。

### 4.2 选股标准

**硬条件（任一不达不买）**：

| 条件 | 标准 | 理由 |
|---|---|---|
| 日成交额（20 日 ADV） | **≥ 5 亿** | 流动性：做T进出场快，-0.5%~-1% 止损必须成交得了；5 亿对单笔 ≤ 0.1% 总资金仓位有充分缓冲 |
| 日内振幅（20 日均值 A） | **≥ 3%** | 差价空间：目标差价 1%~2% 的稳健型操作、A=3% 才给半仓 T 的进出空间 |
| 趋势形态 | **向上趋势或箱体震荡** | 下跌通道的"高抛低吸"是接飞刀——黑名单第 2 条管辖 |
| 基本面 | **同短线仓硬排雷 3 项**（4.1 选股标准的底线，参照 1.2） | 立案 / 退市红线 / 流动性——做T仓短周期持有，不另做加严 |

**加分项（不强制，优先级更高）**：

- 当日 / 主力主线板块（半导体 / 光模块 / PCB / 创新药 / 工程机械出海 / CXO 等）：板块资金流入 + 个股跑赢 ETF
- 机构调研密集（近 1 个月 200+ 家）：题材发酵概率高
- 北向 / 大单资金净流入：开盘方向概率提示

**禁区**：

- 高位纯 AI 情绪票（无业绩、无订单、靠公众号吹的）
- 近期大额解禁（解禁量 > 流通盘 10% 且在 3 个月内）
- 公告日（业绩预告 / 重大事项披露前一日）
- 资金持续流出的板块权重（如新能源 / 银行 / 保险阶段性弱势）

### 4.3 三种战法

#### 战法 A：尾盘买入次日卖出（最稳，频次最高）

| 要素 | 标准 |
|---|---|
| 时间 | 14:30 - 14:50 观察，**14:57 收盘集合竞价起挂单**（A 股收盘集合竞价时段 14:57 - 15:00）|
| 信号 | 股价站稳 5 日线 + 尾盘 30 分钟成交量 ≥ 日均 1.2 倍 + 当日涨幅 1%~3% |
| 涨幅边界 | < 1% 是弱势不碰；> 3% 是追高——黑名单第 4 条（战法 A 是日内唯一允许"接近涨幅上限"的形态，但仍不越线） |
| 退出 | 次日 9:30 - 9:45 不达预期即市价出；达 +1.5% 即出 |
| 止损 | 次日开盘跌破买入价 1% 即走（不接受"等反弹"——黑名单第 3 条） |
| 仓位 | 单只 ≤ 短线资金 50%（即 ≤ 总资金 5%） |

#### 战法 B：强势股低吸（盈亏比高，频次中等）

| 要素 | 标准 |
|---|---|
| 标的 | 上升趋势中的主线龙头（同 4.2 选股） |
| 买点 | 缩量回调至 5 日 / 10 日线 或 15 分钟 60 均线 |
| 退出 | 反弹至前高附近减半；突破前高回踩不破可加至第 2 笔（注意本子模式最多 2 笔建仓） |
| 止损 | 跌破 10 日线无条件离场 |
| 要求 | **盈亏比 ≥ 2:1**——建仓前计算：买点距 10 日线距离 vs 前高距买点距离 |

#### 战法 C：趋势突破（需要胆量，频次最低）

| 要素 | 标准 |
|---|---|
| 信号 | 放量突破关键压力位 + 成交量放大 ≥ 30% + 板块集体启动 |
| 买入 | 突破后回踩确认（**不追首根大阳线**——黑名单第 4 条；战法 C 的容错率高、但仍按"低吸"纪律收口） |
| 止损 | 设于突破点下方 3% |
| 适合 | 板块集体启动首日的龙头股 |

> **三战法的频次与权重（实战经验）**：A:B:C ≈ 6:3:1。A 频次最高、确定性最强但单笔空间小；B 频次中等、盈亏比最优；C 频次最低、需要胆量与板块环境配合——日常以 A 为主、B 辅助、C 偶尔出手。

### 4.4 操作纪律（写死即可执行）

#### 单次止损

- **-0.5% ~ -1% 立即止损**（浮亏口径，加权成本价）
- 与短线仓 -3%~-5% 的区别：做 T 高频且单笔金额大（≥ 5000 元），-3% 已经吃掉单笔目标差价的 1.5 倍以上

#### 时间止损

- **1~3 个交易日未达预期即走**（含当日强制平仓）
- "反正 T 失败了拿长一点" = 黑名单第 2 条（计划外补仓摊成本）——T 失败的下一笔不是"再买一笔摊薄"，是"按计划退出"

#### 连续止损

- **连续 2 次止损（不论浮亏额）暂停本子模式 1~3 天**
- 比短线仓 5 笔 / 3 日**更严**——做 T 频次高（每周 5~10 笔），5 次才停等于无监督
- **频次折算**：做 T 子模式的 2 次连败计入总连败计数 = 短线仓 1 笔亏损计数（governance 1.1 台账总表已登记）——避免做 T 高频干扰主层连败判定；解冻后本子模式日上限减半（5% → 2.5%），连续两笔盈利平仓后复位

#### 日内止损

- **当日累计亏损达 2%~3% 强制停手**（不论笔数）
- 触发后当日不再开仓；次日恢复但本子模式日上限减半（5% → 2.5%）
- 连续 2 天达日内止损 → 触发本子模式连续止损的 2 次暂停

#### 佣金条件（不达标不做 T）

| 单笔金额 | 佣金成本（万 1 + 印花税 0.05% 卖出单边） | 经济意义 |
|---|---|---|
| ≥ 5000 元 | ≈ 0.075%~0.1% 往返 | 目标差价 1% 时净收益 ≈ 0.9%，可接受 |
| 1000~5000 元 | ≈ 0.2%~0.5% 往返 | 目标差价 1% 时净收益 ≈ 0.5%~0.8%，边际可接受 |
| < 1000 元 | ≈ 1%+ 往返 | 目标差价 1% 时净收益 ≈ 0 或负，**禁止** |

> 单笔 < 5000 元在数学上仍可做，但本纪律层**门槛设为 ≥ 5000 元**——避免小额笔数过多导致年摩擦吃掉期望值（governance 2.6：摩擦 = 往返笔数 × ~0.13%）。**目标差价**：稳健型 1%~2%（与单笔 ≥ 5000 元的佣金条件匹配）、激进型 2%~5%（仅在 ADV ≥ 8 亿的高流动性主线龙头，且单笔 ≥ 1 万时才用）。

#### 美联储议息等大事件前后（特殊窗口）

- 美联储议息 / 国内重要政策窗口 / 财报披露密集期等"高不确定性窗口"前 1 个交易日，本子模式日上限减半（5% → 2.5%）；事件落地后视结果调整（降息 / 利好落地 → 恢复；鹰派 / 利空 → 本子模式暂停 1~3 天）。
- 写入周报第 1 步"合规"段的事件窗口清单（governance 第四节）。

### 4.5 与现有纪律的兼容性

| 黑名单条款 | 本子模式如何兼容 |
|---|---|
| 第 2 条：计划外亏损补仓摊成本 | **做 T 失败不补仓**（4.4 时间止损）；底仓与做 T 仓严格隔离 |
| 第 3 条：止损价到了不走 | **0.5%~1% 必走**（4.4 单次止损）；当日达日内止损 2%~3% 强制停手 |
| 第 4 条：追涨停 / 追当日已大涨 | **战法 A 要求当日涨幅 1%~3%**（不是 ≥ 5%）；战法 C 不追首根大阳线 |
| 第 7 条：盘中临时改变既有计划 | **建仓时即写死退出计划**（4.3 各战法）；盘中只执行、不决策 |
| 第 9 条：卖出后懊悔式回买 | **当日闭环**（4.1 持仓周期）；次日走完即结束，不复买 |

| 与其他纪律的衔接 | 衔接方式 |
|---|---|
| 通用第四节 连败 | 做 T 子模式 2 次连败 = 短线仓 1 笔亏损计数（频次折算，已登记台账） |
| 通用第八节 止损当日全局冻结 | 做 T 当日日内止损 2%~3% 触发 = 当日全局冻结（含底仓与其他层），与通用同向叠加（不是替代） |
| portfolio-risk 第三节 ADV 门槛 | 做 T 子模式 ≥ 5 亿 > 短线仓 ≥ 1 亿；本子模式买前必查 |
| portfolio-risk 第二节 行业集中度 | 本子模式持仓计入短线层；同行业累计 ≤ 短线层 50%（避免做T把单一行业打满） |
| trading-discipline.md 第三节 "T+0 日内回转" 被排除 | **本子模式不属此排除**——此排除指"给存量持仓降成本的 T+0 执行技巧"，本子模式是独立的做 T 仓 |

### 4.6 复盘参数补登

- 本子模式**独立统计**：胜率、平均盈亏、期望值（按 4.4 单笔 ≥ 5000 元的笔数统计）
- 滚动窗口：**50 笔**（与短线仓同；不混入短线仓统计）
- 期望值连续两个不重叠 50 笔窗口 < 0 → **停用本子模式**（不是停用短线仓）
- **额外必录字段**（governance 附录 C trades 字段补登）：
  - **子模式**（短线 + 子模式 = 做T）
  - **战法**（A 尾盘 / B 低吸 / C 突破 / T 日内）
  - **单笔金额**
  - **佣金占比**（往返费用 ÷ 毛收益；本子模式必录，短线层选录）
- **噪声止损率**（governance 2.3 专项）：做 T 子模式 -0.5%~-1% 止损处于日内波动核心区，噪声止损率预期 > 短线仓——**连续两个季度噪声止损率 > 70%** → 止损区间整体下移一档（更严，如 -0.5%~-0.8%）；同时优先收窄的是"战法 A 选股标准"（如要求涨幅 1%~2% 更严、缩量条件更严），不是放松纪律

## 五、连败参数（覆盖通用默认）

触发：连续 **5 笔**计划内亏损平仓（硬止损、时间止损均算；计数规则同通用：计划内盈利平仓重置，平手不计数，违纪交易不计入但违纪盈利不重置）。

1. **立即**：冻结本层新买入 **3 个交易日**（已挂条件单照常执行）。
2. **解冻后**：本层额度减半（10% → 5%），一笔计划内盈利平仓后恢复。
3. **跨层升级**：与中线/长线层同时触发时，按通用文档第四节执行全局冻结。

> 做 T 子模式的连败单独计算（2 次 / 冻结 1~3 天，详见 4.4），不计入本节短线仓连败——其频次折算方式（2 次 = 1 笔）已登记台账（governance 1.1）。

## 六、复盘参数

- 滚动窗口：**50 笔**，独立于其他层统计；基准 = 0（绝对收益，governance 2.1）。
- 额外必录字段：**买入时板块所处阶段**（发酵前 / 初段 / 后段）——用于验证"只低吸"是否真的执行，以及低吸时点的胜率差异。
- **噪声止损率**（governance 2.3 专项）：止损平仓后 3 个交易日内收盘价收回止损价上方 → 记一次噪声止损。本层 -3%~-5% 止损处于日常波动区边缘是**已知设计风险**——连续两个季度噪声止损率 > 50% → 止损区间整体上移一档（走变更流程），同时优先收窄的是低吸时点，不是放松纪律。
- 期望值连续两个不重叠 50 笔窗口 < 0 → 停用本层（学费交够了，停止交学费）。期望值按净值口径（通用七节、governance 2.6）——本层高频，摩擦占期望值比重最大，毛值口径会把"实际亏摩擦"的策略测成"活着"。
- 做 T 子模式独立统计与停用见 4.6；本节"停用本层"指停用短线仓（含做T子模式一并停用）。
